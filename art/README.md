# Art

Source art for *Petal of the Void*. These are the full-resolution originals.
The game uses copies under `game/assets/`, so edit or replace files here
first and then re-copy them.

## Layout

| Folder | Contents |
|---|---|
| `story/chapter-NN/` | Illustrated story panels, numbered in reading order. Used for cutscenes. |
| `key-art/` | Standalone hero images: title screen, loading screens, store listing. |
| `characters/` | Character reference sheets and sprite sources (to come). |
| `environments/` | Location concepts and backgrounds (to come). |

## Notes

- The images carry Gemini's sparkle watermark in the bottom-right corner. The
  game crops it out when it displays them; crop it in the source file for any
  store or marketing use.
- Source images are 1408x768 (about 16:9). Keep new story panels at that ratio
  so they fill a landscape phone screen.
